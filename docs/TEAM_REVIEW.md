# 队内复核清单

当前代码和文档是 AI 辅助阶段成果，需要队内独立理解、验证和修改。不要把运行通过直接等同于比赛问题已全部解决。

- [ ] 确认 50 个目标的实际提交范围，保留 Aroma 与 Flavour 对应关系。
- [ ] 查找原始 0–6 分或标准化转换参数，决定绝对标定方案。
- [ ] 复查逐字段变换与匹配异常，判断截尾是否改变真实信号。
- [ ] 独立复跑第一问，检查折内预处理和逐维误差。
- [ ] 对反直觉、低稳定性 Top-3 独立研究，不直接采用未论证的机理。
- [ ] 补充每维关键因素的原始文献、单位与感官阈值。
- [ ] 独立评价生成模型是否优于简单重采样，记录失败风格。
- [ ] 查清缺陷项的浓度映射及阈值，明确 Stale hops 代理限制。
- [ ] 区分非平凡迁移、原样保留失败和缺失源值条件下的检查。
- [ ] 补上聚合量的一致性、化学与酿造约束。
- [ ] 记录核心建模、算法设计、求解分析由谁独立完成和如何验证。
- [ ] 补全 AI 工具版本、关键交互、采纳内容和人工修改情况。
- [ ] 最终论文遵守匿名、正文页数、引用、附录源程序与独立承诺书要求。

后续每次实质修改应保留新输出目录、配置、运行环境、检验结果与 Git 提交。队员复核尚未发生的项目保持未勾选。
