# 真实品评与化学复核实施方案

本文件是未来试验方案，不是已完成试验。现有计算没有生成新的实物啤酒，也没有取得新的品评记录。

## 1. 开始试验前的条件

先把统计化合物谱转化为具备可追溯原料和工艺的可制备小试方案，记录每批来源酒、酿造/处理方式、批号和保存时间。匿名历史编号本身不能代替当前实物批次。本阶段的严格浓度凸混合未发现满足四项不增加约束的非平凡方案，因此不能照着统计谱直接称量成酒。

由具备条件的实验室确认配方和制备流程，实际接触饮品的原料采用合适食品级材料。不同终点不得擅自用非食品分析标准品加标饮用。取得成年参与者知情同意，说明饮酒量、退出方式和过敏信息；按所在机构要求执行招募与试验管理。

## 2. 化学复核

至少制备3个独立批次的对照与候选。每批保留DMS、双乙酰、4VG、trans-2-nonenal的独立测量，并由实验室提供单位、标准曲线、空白、重复测量、检测限LOD与定量限LOQ。DMS按ug/L，其余三项按mg/L统一；0.1 ug/L的nonenal文献参考值换算为0.0001 mg/L，不能漏掉1000倍换算。

非正值或未检出应记为带上界的左删失测量，不填成已知浓度0。对仪器记录采用[0,LOD]等有依据的区间。若要求最保守的不增加，需要候选浓度上界不超过来源浓度下界；两者都未检出并不能证明绝对未增加。基质加标回收与混合后反应/挥发也须实际复核，不能用历史表中“calibrated=yes”代替新批次校准。

预先记录阈值使用的是哪项研究、哪种基质和什么测量协议。以附件DMS=19 ug/L、双乙酰=0.09 mg/L、4VG=0.2 mg/L为条件参考，nonenal=0.0001 mg/L来自外部原始研究；同时报告0.5、1、2倍阈值。OAV只作条件风险诊断，不直接判定个体感知或真实缺陷出现。Stale hops作为独立感官终点评分，不冒充某一种已测化合物。

## 3. 盲评与重复批次

建议准备30名完成训练的成年品评人员，3个独立批次分3次评定，每次包含一个来源对照和一个候选；必要的参考酒另供训练，不与确认性终点混算。规模是规划建议，不表示本项目已招募或本队3名成员能代替专业面板。

由不参加评分的管理员生成私有三位数随机编码及处理映射，每批让两种呈现顺序各占一半。映射与正式随机种子不在公开仓库发布，评分者与直接接触评分结果的研究者在锁库前均不知道对应条件。统一杯型、体积、温度、静置时间和光照，参考原研究的黑色杯与12–16摄氏度条件；记录偏离，不将其视作所有风格通用最佳温度。

评分者填写原50个0–6分属性，另填预定义Tripel风格符合度0–6。该符合度属于新定义终点，应通过参考酒训练，不能冒充历史原评分卡已有变量。提前锁定排除/退出和缺失处理规则，不因结果是否显著决定删人或删批次。

空白采集表位于outputs/stage4/protocol/blank_panel_rating_template.csv。它只含字段名，没有虚构人员评分。正式实施时每行是一个人、一个批次、一个条件的观测；保留原始整数评分、匿名人员编号、盲码、日期与批次。解盲后condition填写control或candidate。

## 4. 评价标准与样本量

主要缺陷终点预先规定为dms、diacetyl、X4vg、t2n和stale_hops。对每人先取候选减对照的批次配对差，再平均其批次，形成独立人员层面的差值；30人×3批不能当90个独立人员。

非劣界暂定0.5分。每项以单侧alpha=0.01构造均值差的上置信限，五项都低于0.5才支持“在该预设界值内没有明显恶化”。这并不等于证明差值≤0；若题目要求严格不增加，必须另外报告实际差值、上界和界值敏感性，不能偷换标准。五项均通过后，再以单侧alpha=0.05检验风格符合度均值差是否大于0。使用标准配对t近似，并另报告分布、个体差异和批次差异；小样本、偏态与外推边界需说明。

样本量使用非中心t分布作规划敏感性。假设人员平均配对差的标准差为0.8分、真实差为0、非劣界0.5、单侧alpha=0.01，达到80%功效至少需29名独立人员；30人对应约82.5%。若标准差为1.0则至少43人。它们是输入假设下单个终点的功效，不是五终点共同通过的80%保证。0.25分界值在标准差0.8时需106人，显示更严格结论成本更高。正式人数应根据独立先导试验的方差和联合成功率再确认。

## 5. 分析、锁库与归档

试验前锁定主要终点、界值、样本量、随机化和分析方案。研究人员获得实际评分后才运行scripts/analyze_trial.py；程序会拒绝空表、未配对记录、重复键和超出0–6的评分。它按人汇总，不把批次重复当独立样本。

保留各终点均值差、置信上界、人员数、批次数和所有失败项。若放宽任何界值或更换候选，只能另列探索分析，并用新的确认性批次验证。盲评失败、仪器不支持或缺陷上界无法满足时，保留失败结果，不用模型预测覆盖实测结果。
