# 队员复核记录模板（逐人填写）

以下字段由实际执行人员填写；空白表示尚未执行，不能用于声称已独立完成。

- 复核人及分工：
- 实际日期及使用环境：
- 本人独立推导的问题、输入和目标定义：
- 本人运行的命令、结果文件和关键指标：
- 与论文不一致或不理解之处：
- 本人对模型、代码或论文所做的具体修改及理由：
- 交叉复核人、复核时间、发现及处理：
- 实际使用的AI工具、版本、关键交互及采纳和人工修改：
- 结论：已核验 / 需要进一步处理（按实际填写）。

第一问复核折内预处理、训练内阈值、非零结果；第二问核对Top-3、岭参数重选范围及化学文献；第三问核对G/J/T、阈值倍率、案例配方、代理检查与实际测量边界。最终另核对官方提交规定与匿名要求。
