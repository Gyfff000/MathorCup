# 最终模型交付与诊断记录

## 运行与检查

- 以 250 款历史样本的 231 个化合物字段、50 个面板均分和七级评分分布训练全数据模型：均分使用既有 ET/GBR 固定等权融合，等级分布使用频率 ET。评分目标来自第四阶段审计表；输出 CSV 的有限小数精度可能改变树模型中近似相等值的划分，因此不能把全数据模型输出当作原始未舍入拟合的逐位复现。
- 保存预处理器、模型、字段顺序、可核验的参考单位与经验变换、目标、包版本和输入 SHA-256。新样本必须提供全部231列、沿用附件1的变换与单位；允许缺失单元格。单位记录是参考浓度单位，输入可能为对数尺度；未核验字段的单位留空。
- 从另一个目录，使用仅含化学字段的三行历史样本文件完成预测，生成 3×50 面板均分、3×50 众数、3×50 中位数及 150 条七级分布。该操作验证无标签推理流程；三行来自训练集，不是独立泛化检验。模型二进制保存在本地并由用户重新训练，不公开上传。
- `run_stage4.py` 增加 `--config`、`--out` 和 `--stage3`，非空输出需显式 `--allow-overwrite`。第四阶段预测和等级外层划分使用配置的折数、重复次数，保形分位数使用配置的 alpha；运行记录写实际配置与配置文件哈希。
- 采用2折、1次重复、alpha=0.2、3棵树的快速验证配置执行完整第四阶段预测：输出记录为2折1次，各酒各留出1次；重新拟合同一校准模型并核对区间下界，最大差约5×10^-9。与 alpha=0.1 的校准分位数在50个属性上均不同。该小模型只用于检查配置生效，不替代原研究成绩。
- 第四阶段新增输出将累计分布平方距离、个人期望 RPS、分布 Brier 距离及个人期望 Brier 分别命名；历史文件中的 `RPS` 字段保留原状，其含义是分布距离。
- 完整测试：54项通过；其中两项使用合成数据验证无标签推理、缺列、重复字段和无限值拒绝。现有结果的研究结论与模型实现测试是不同层面的证据。

## 新增描述性诊断

固定历史留出预测、不重训，核心30项共7500条啤酒—属性记录，实测面板众数非零1648条，其中27.85%预测为0，24.33%预测等级与观测众数一致。`A_hops_noble` 的49条非零记录全部预测为0。逐维、逐风格和7×7混淆表记录在 `outputs/stage5_diagnostics_20261028`。

分割保形结果按面板人数分组：3—4人组覆盖率74.00%，含12款不同酒、750条重复测试啤酒—属性记录；5—7人组86.89%，8人及以上组92.94%。这些是混合属性与重复划分的描述性比例；它们不构成按组覆盖保证。各属性、风格和面板人数的覆盖率、宽度及独立酒数保存在 `coverage_by_group.csv`。

零/非零两阶段先导：同一三折五次按酒划分中，先估计0分概率，再用非零质量作为权重估计1—6分条件分布，按概率乘积合成七级分布。分别与原200棵树频率ET、每个ET模型均为32棵树的频率ET比较；两阶段含多个ET，总计算量并未匹配。相同单模型树数下，核心非零众数一致率从24.76%升至25.49%；差值0.73个百分点，按风格分层、以酒重采样的固定OOF条件95%区间为[-0.91，2.30]个百分点。核心累计分布平方距离从0.021779变为0.021995；原200棵树频率ET对应0.021784和24.33%。分布分数与非零命中共同考虑，当前不替换主模型。原始逐酒概率、脚本、设置与差值结果保存在 `outputs/stage5_two_stage_20261028`。
