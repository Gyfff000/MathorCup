# 期刊模板来源与赛事格式适配

## 参考依据

1. 《计算机学报》模板示例：Qiliang Fan 发布的 [Chinese Journal of Computer Template](https://www.overleaf.com/latex/templates/ji-suan-ji-xue-bao-mo-ban-chinese-journal-of-computer-template/kfdwbwzdmpmb)，该页面标示 CC BY 4.0。示例展示标题、报道性摘要、分级标题、公式、图注、三线表和顺序编码参考文献；本项目没有复制其正文。
2. 期刊论文示例：高志、武玉伟、贾云得，《混合曲率空间中的几何自适应元学习方法》，《计算机学报》，2024，47(10)，DOI: 10.11897/SP.J.1016.2024.02289。[期刊论文 PDF](https://cjc.ict.ac.cn/online/onlinepaper/gz-2024928105658.pdf)。通过期刊检索结果核查了摘要、作者和期刊信息；本机直接下载连接被重置，因此本轮不能声称逐页目视核验该论文 PDF。
3. 实际使用的文档类来源为 Zeping Lee 开发的 [latexstudio/chinesejournal](https://github.com/latexstudio/chinesejournal)，仓库明确称其为以《计算机学报》要求为基础的中文期刊模板框架，并注明不保证用于该刊投稿。原始 `cjc.cls`、`cjc.dtx` 和 LPPL 许可证保存在论文目录；`mathorcup-journal.cls` 是为当前 CTeX 及赛事要求改写并重命名的适配版，并非期刊官方类文件。

## 按赛事规范调整

- 首页放中文题目、摘要、关键词；第二页为独立目录页；正文从第三页开始编号，页码置于页脚中部。
- 不使用期刊刊名、期号、作者、学校、联系方式及页眉；正文使用中文双栏，摘要采用跨栏排版。
- 图注放图下方、表题放表上方，正文以编号引用；表格使用三线表，并对跨栏宽表采用双栏通栏排版。
- 参考文献按正文首次出现顺序编号；来源数据的网络地址及访问时间予以列明。附录保留因素表、运行命令、项目代码和论文排版源码。
- 赛规要求正文不超过30页、附录页数不限；请以最终编译版本逐页核验。签名承诺书、比赛编号与 AI 使用记录须由队伍按实际情况准备。

## 维护

直接编辑 `paper/latex_20261028/main.tex` 和 `mathorcup-journal.cls`。在该目录运行两次 `xelatex -interaction=nonstopmode -halt-on-error main.tex` 更新目录和交叉排版。`scripts/build_latex_revision.py` 用于从阶段 Markdown 重新生成主文件，会覆盖对 `main.tex` 的直接修改。
