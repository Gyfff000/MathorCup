# 第二问方法记录

**输入与网络。** 先核查附件 1 的字段顺序与附件 2 的完整秩相关结构一致性，生成明确别名表。给定矩阵按 |r|≥0.7 建边，记录正负相关与绝对权重；导出节点、边、模块及 0.6、0.7、0.8、0.9 的阈值敏感性。模块包括孤立节点，不能把模块数直接解释为已经发现的独立生化通路。

**模型。** 标准化处理后的特征为 Z，目标中心化为 Yc。W 为截断后的有符号相关，Dii=Σj|Wij|，L=D−W。最小化 ||Yc−ZB||² + α||B||² + λ tr(BᵀLB)，解线性系统 (ZᵀZ+αI+λL)B=ZᵀYc。固定 α=20、λ=5 作为研究基线。符号拉普拉斯为半正定，配合 α>0 保证数值求解；测试覆盖负相关边情形。

**候选因素。** 每个目标按标准化特征的系数绝对值取 3 个化合物或元素，排除 pH、色度、混合指标和聚合总量。输出含系数方向、边际秩相关、来源元数据、网络模块和待人工核查的化学解释字段。没有把一个整体喜好模型的重要度用于所有感官目标。

**稳定性。** 用 100 次样本有放回重采样，每次重新估计预处理和 Spearman 网络，再重新拟合模型并计入 Top-3。没有仅对已有排名重抽样。另与无图岭回归、边际 Spearman 排名的 Top-3 比较 Jaccard。固定网络与重建网络不是同一个估计问题，当前频率同时反映样本和网络变化。

**解释边界。** 全数据给定矩阵仅用于描述性分析，第二问没有借此声称独立样本的预测增益。回归系数、相关性和入选频率都不能证明化合物因果。若目标的预测能力较低或 Top-3 不稳定，必须保留这些失败信息。当前化学论证仅附来源、单位和既有缺陷描述，尚不构成针对每个感官维度的完整文献论证。

**成果。** 每维 3 项共 150 条候选、全部变量的入选频率、方法一致性、网络边与节点、阈值敏感性。反直觉项和低频项原样保留为需要研究的问题，不能挑选结果包装成已确定机理。

**队内下一步。** 逐目标查证候选的感官作用、浓度/阈值和交互；检查已知关键分子缺席时的共线替代与模型不足；验证 α、λ 与阈值敏感性；结合独立留出解释、多任务稀疏化或模块解释进行改进。不得用人为填入预期化合物掩盖模型实际输出。
