# 第三问方法记录

**目标。** 用共享低维结构减少小风格样本数不足的影响，生成给定风格的附件尺度化合物或理化描述符，并输出固定感官预测器下的画像。生成与迁移均为统计研究基线。

**训练与诊断。** 按风格分层保留 20% 原始样本，训练预处理、PCA 和生成分布时均不使用留出集。训练 10 维 PCA，每风格保留其均值；局部协方差以 n/(n+10) 与 Ledoit-Wolf 汇聚协方差混合。为 Tripel、Kriek、Lambic 各生成 40 组，解码后限制在训练字段的 1%—99% 范围。低维高斯和范围投影是明确假设，不能推导酿造可实现性。

**生成评价。** 对真实风格留出样本计算各字段非缺失观测的 KS，另在训练预处理表示上计算有偏 RBF MMD²，带宽由真实参考样本的非零距离中位数确定。保留从真实训练风格重采样得到的 MMD 参照。记录最近训练距离和精确复制比例。稀有风格留出数很小，距离估计本身不可靠，MMD 没有优于简单重采样时也如实保留。

**风格评价。** 另训练正则化 LogisticRegression 分类器，对真实留出集报告平衡准确率，再查看生成样本的目标风格概率。该分类器与生成模型共享训练样本，属于内部诊断；不作为独立化学鉴定。通过分类器并不能证明实际风格成立。

**感官画像。** 调用第一问预先指定的岭回归全数据拟合模型，输出原始连续目标尺度。输出的 ASSUMPTION 等级只用于经验分位展示。生成模型的留出样本可能被全数据感官代理见过，因此此画像不用于声称独立感官验证。

**迁移搜索。** 对 Pils/Lager 样本编码，增加 Tripel 与 Pils/Lager 训练潜均值之差，解码为目标方向。沿该方向搜索 50 个连续权重。候选经过范围投影，DMS、双乙酰、4VG、trans-2-nonenal 四个字段逐项投影到不大于源值。Stale hops 没有直接化合物字段，以固定感官模型的预测不增加约束。要求 Tripel 分类概率超过原始源样本及“仅截尾”的对照至少 0.01。

**失败处理。** 若没有满足约束且有风格移动的候选，保留原样并标为 no_nontrivial_candidate_found_source_retained，绝不计作成功。源缺陷缺失时仅可相对插补值检查，必须另行标记。保留源的极低缺陷值可能使样本越出训练经验边界，诊断中记录越界数。没有实测值时不能声称满足真实缺陷要求。

**阈值缺口。** 部分字段只在多数校准配对中与原值一致；trans-2-nonenal 的附件阈值缺失，Stale hops 也是感官描述。因此本阶段执行更保守的逐字段测量值不增加与预测代理约束，不声称已完成全部绝对浓度/OAV 阈值认证。

**聚合指标。** 五个综合字段随谱共同生成，但没有建立原作者全部聚合公式；它们的精确代数一致性未获保证。只在经验范围内也不能证明所有化学组合合理。后续应分开生成基本成分与重算综合指标。

**队内下一步。** 与真实风格重采样、凸组合生成等简单方法比较；增加成分数、汇聚强度、边界和迁移步长敏感性；完成浓度/阈值字典与实际酿造约束；若有条件进行真实盲评。任何第三问的优化成绩都必须与模型外证据区分。
