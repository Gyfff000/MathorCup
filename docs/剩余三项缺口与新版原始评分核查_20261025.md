# 三项剩余缺口的可完成范围与新数据核查

日期：2026-10-25。

## 本次发现

原作者 [Zenodo v4](https://zenodo.org/records/23624915) 于2026-10-24发布，新增 Raw sensory data anonymized.csv。此前使用的[v3](https://zenodo.org/records/10653704)文件清单没有这一项。上一轮没有追踪最新版，因而不能把上一版论文的“尚未取得评分锚点”解释为已经穷尽公开数据。

本次已下载新增CSV和原始补充工作簿，按发布页MD5逐一校验通过。外部原件保存在仓库外的external_sources目录，未公开再分发。仅将核查结论记入本记录。

新增原始评分为2197行、56列，包含16名匿名品评人员、250个beer_name和50个评分目标，50项评分均在0–6且无缺失。A/F_ester_fruity与附件的A/F_esters_fruity需要显式别名映射；同酒同人有187条重复记录，不能当独立啤酒样本。

## 对应关系尚未核实

beer_name与附件beer的编号集合重叠250个，并不证明同号同酒。直接按同号核对风格字符串仅12/250相同；原始文件使用15类粗风格，而附件使用22类细风格，且存在Tripel对Dubbel等差异，需追查匿名编号映射和分类口径。

从新原始评分按品评人员、各属性分别标准化，尝试总体/样本标准差及酒内均值/中位数四种简单汇总，按同号与附件4.csv比较，平均绝对偏差约0.572–0.575，未重现附件标签。不能把这些尝试当作已经找到原作者变换流程，更不能自动合并。

公开工作簿Supplementary File S1和S4的250个编号与附件风格全部一致，说明后续应沿原始评分到补充表的编号/预处理链继续追查。若利用感官标签匹配推断编号，需要明确这种映射对标签的依赖，并以独立元数据和变换重现证据核实，不能将强制配对伪装成独立真值。

## 三项能力与条件

1. 原始绝对评分：目前已经取得新的原始数据来源；仍需核实同酒对应、重复品评处理和聚合定义。确认后可建立原始尺度的直接预测或校准模型，按酒分组验证；未经确认不改写为已完成绝对标定。
2. 完整化学标定：可继续核对工作簿、原作者程序、单位、浓度变换、阈值、检测限和综合量公式。有依据的部分能够计算和检验；来源未给出的仪器校准、回收率或新样本浓度需要实测，不从统计拟合冒充测量。新工作簿的Calibrated chemical dataset为250×73（含3列元数据），并非231个输入均有绝对定量。
3. 真实品评：可完成随机盲法、对照、重复测量、评分表与统计分析设计；生成化合物谱需要先由具备条件的人员制备/酿造并进行实际品评。现有公开Validation表是原作者试验，不能作为本项目新生成候选的真实品评。

## 对现有稿件的影响

现行20261025修订稿和第三阶段结果保留，仍准确记录当时已运行的计算与证据范围。本记录是新增数据核查，不表示已更新主模型或完成绝对评分恢复。优先研究原始评分与附件对应，再决定是否重训；不把全部剩余工作推给队员，也不宣称公开资料已经全部补齐。
