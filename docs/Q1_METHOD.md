# 第一问方法记录

**研究目标。** 先在附件提供的连续感官尺度上建立可检验预测，再单独处理绝对评分标定。第一阶段对全部 50 个目标输出，Aroma、Flavour 与其余维度在字典中区分，便于按官方明确口径筛选。

**处理流程。** 附件 1 与 4 按 beer 对齐。排除编号、条码和风格作为预测输入。预处理依次为训练数据分位截尾、训练中位数插补与标准化，均由 Pipeline 管理。负值保留其附件尺度意义，不直接当作负浓度，不统一取对数或反对数。

**验证。** 三折、两次重复按风格分层；最少类别有 3 个样本，满足此折数。每个样本每次重复只被留出一次。岭回归与 PLS 在外层训练数据中再用三折选择 alpha 或成分数。模型包括训练均值、岭回归、PLS 和多输出 ExtraTrees。所有候选模型共享外层划分，分别报告，预先指定岭回归为后续感官代理，避免看外层结果后再选择并声称独立成绩。

**指标。** 每维 MAE、RMSE 和 R²，再计算维度宏平均。重复留出预测取均值后计算总体表，折级指标另存。各风格误差只用该风格的留出预测。没有用模型的训练拟合成绩替代泛化成绩，没有报告未经校准的 95% 覆盖率。

**缺失压力实验。** 对每个外层留出集额外遮蔽 0%、5%、10%、20% 单元格，同一折使用同一随机数流形成可比较的遮蔽掩码，直接经过既有训练预处理预测，不在留出数据上重新估计中位数。该实验是 MCAR 压力测试，不能代表所有真实缺失机制。

**0–6 分的边界。** 未找到配对原始评分、原始均值/标准差等锚点，绝对分数仍不能唯一恢复。ASSUMPTION 文件按每个训练折的目标分位数划分七档，预测等级取重复结果的平均后舍入。这只能表示相对经验等级，不具有真实“0=不存在、6=压倒性”的保证，不能拿同一构造标签的准确率当作真实评分精度。数据集中很多目标有大量相同值，分位边界也可能重复。

**成果。** OOF 连续预测、逐维/逐风格/逐折误差、内层参数、缺失敏感性、假设分级和最终全数据岭回归系数。最终模型的二进制文件保存在 private/，供第三问使用，不在公开仓库分发。

**队内下一步。** 确认原始评分来源和最终维度；检查截尾对真实极端值的影响；进行新风格外推、变量组消融或独立样本验证；决定是否研究稀疏/多任务/非线性改进。当前模型比较为阶段基线，不是最终竞赛算法决定。
